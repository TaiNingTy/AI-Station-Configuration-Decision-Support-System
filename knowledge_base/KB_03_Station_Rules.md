# KB_03 — 站点配置规则 (Station Configuration Rules)

> 从客流与场景推导站点配置的规则库。Demo 用简化版。

## 1. 月台/车位数量
- 车位数 n ≈ 高峰客流(人/小时) ÷ 单车位通过能力(300 人/小时)，向上取整。
- 例：高峰 500 人/小时 → 500/300 ≈ 1.7 → 2 个车位。
- 各等级车位上限（= 车位数 × 300 人/小时）：C 级 1（≤300）、B 级 2（≤600）、A 级 4（≤1200）、S 级 6（≤1800）。客流超出本级上限时应升级为上一等级设计。

## 2. 闸机/进出控制
- 无闸机（开放式付费）：适用 C 级。
- 单向闸机 ×2：B 级。
- 双向闸机 ≥ 4：A 级及以上。

## 3. 候车设施
| 场景 | 雨棚 | 座椅 | 实时到站屏 | 屏蔽门 |
|---|---|---|---|---|
| C 级 | 简易雨棚 | 2 | 可选 | 否 |
| B 级 | 全覆盖雨棚 | 4–6 | 是 | 否 |
| A 级 | 全覆盖 | 8+ | 是 | 建议 |
| S 级 | 全覆盖+封闭候车 | 16+ | 是 | 是 |

## 4. 接驳配置
- 郊区通勤站（B/C）须配：自行车位 ≥ 10、P+R 车位（如用地允许）。
- 城区站须配：与人行系统无缝衔接、共享单车停放区。

## 5. 参数推荐输出要求
每条配置建议须包含：**参数值 + 依据（引用哪条规范）+ 置信度**。

## 6. 冲突处理优先级
当规划目标与工程约束冲突时，优先级：
1. 安全 / 无障碍硬约束（最高，不可让步）
2. 工程可实施性
3. 规划服务水平
4. 成本与美观
